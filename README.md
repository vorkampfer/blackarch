# BlackArch scripts, tips, tricks, links, and guides I created to help people who are new to BlackArch become powerusers.
1. Here are some tips to help you to become a power user on BlackArch, and hopefully save you some time.
2. Click [HERE](https://medium.com/@0xchilli/fixing-black-arch-invalid-signatures-6ce2d513e60e) to see one of the main problems new people have when using the blackarch platform. It is the Levon Kayan bug. Basically, this is easily fixed my manually updating your ~/etc/pacman.d/mirrorlist and ~/etc/pacman.d/blackarch-mirrorlist to a properly working server. I recommend using and http server.
3. inspect_eee.sh is a script that helps block or disable Energy Efficient Ethernet on your BlackArch. Why? Because it sucks and if your Ethernet card is a Realtek it can disable the card (put it to sleep) and it will not wake up. Thus disabling your internet. The script is a workaround for that bug.
